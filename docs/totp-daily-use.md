# CampusOps 动态验证码入口锁：日常使用

RC13：已绑定的RC7—RC12旧格式需要由所有者使用私有工具升级，**沿用手机原CampusOps记录，无需重新扫码**。
日常包不含创建、换绑、迁移或恢复实现；旧格式不能继续登录，也不会自动升级。步骤见 `totp-upgrade-rc13.md`。
DPAPI同时保护失败计数、冷却与已用时间步；镜像字段不一致时保持锁定。完整旧快照回滚仍属于本地防护边界。

本功能自0.2.0rc7加入：Google Authenticator兼容、六位数字、30秒时间步、SHA-1标准参数；允许当前时间前后各一步，已消费步不可再次解锁新会话。
这是单因素、离线的正常入口访问锁；不是完整防盗版、许可证或远程授权系统。源码修改、本机管理员、调试、秘密提取不在其防护保证之内。

1. 将完整日常运行包解压到D盘，保留runtime等目录；使用Windows x64、Microsoft Edge、.NET Framework 4。
2. 首次未绑定时只显示“尚未由所有者配置访问验证，请联系所有者”。日常页面没有扫码、自助绑定、密码、注册或恢复按钮。
3. 所有者在受控本机单独运行维护包，扫码并输入动态码确认后才完成绑定。实际所有者绑定须由本人操作，开发验收使用的测试绑定不随包分发。
4. 日常输入验证器当前六位码，点击“解锁”。以字符串处理，开头的0保留；输入框遮挡内容，只有提交才验证。
5. 换页和普通重运行保持当前会话；点击“锁定 / 退出”清除当前会话访问凭证和业务界面状态，不删除记录、不重置预算。
6. 新窗口、新会话、服务重启或整页刷新可能需要重新输码。A窗口解锁不会解锁B窗口。已经使用的验证码须等待下一轮；初始化确认也会消费其对应时间步。

默认会话绝对期限2小时，无有效用户交互30分钟到期，使用单调时钟。读取数据、自动重运行不延长期限；明确导航、刷新和受保护命令计为交互。
过期检查在后续交互与每个服务调用前执行。过期时的批准、生成、重置不会执行；重新解锁也不会重放旧按钮，必须再次明确操作。
已由有效会话发起的工作流可以完成并保存，但不会因重新解锁自动生成或批准。

连续5次错误冷却60秒。绑定、失败限制和重放状态共用独立SQLite状态库，跨页面与重启保持；不要通过更改时钟、删除文件、重置演示库或更换解压目录处理验证失败。
TOTP始终用真实系统时间；预约“演示时段”与API的UTC日预算互不影响。电脑或手机时间不准时请自行校准，程序不会改系统时钟。

安全状态固定在 `D:\CampusOps\var\security\totp-state.sqlite3`，与业务库、桌面会话及预算账本分离，不由环境变量、URL或演示开关更换。
秘密仅以Windows DPAPI CurrentUser密文保存；通常依赖绑定时的Windows用户和电脑。换用户或电脑不能解密时保持锁定，由所有者在受控维护环境重新配置。
状态缺失、损坏、不可读、不可解密均拒绝进入，不自动删除重建，不提供免验证回退。

真实AI仍需原有独立的模型配置、明确启用及费用保护。动态码不授权模型费用，也不证明审批别名是真实个人身份。
日常包不含真实动态码种子、二维码、已解锁会话、真实数据库或API Key。旧RC6包未加此锁，归档保留需由所有者受控保管；本锁不会追溯修改旧程序。
源码评审、队友使用和评委访问方式待所有者确认，不提供公开种子或免验证评审后门。

所有者已选择多电脑共用手机中同一条CampusOps记录：新电脑先保持锁定，由所有者通过独立维护工具受控导入同一设置密钥，并在目标Windows用户下重新DPAPI保护。
不能把源电脑的加密状态库直接复制过去，也不能把设置密钥塞入公开包。普通接收者不应拿到Owner工具。
其他实际电脑的运行与本人码解锁仍需按 `totp-other-pc.md` 实测；本机换目录通过不能称为异机通过。
