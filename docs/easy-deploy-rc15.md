# RC15 新电脑首次部署：只看这一页

所有者使用私有完整包 `CampusOps-GearShift-0.2.0rc15-Owner-Setup-Private.zip`。
普通使用者只接收日常包 `CampusOps-GearShift-0.2.0rc15-Windows-Deploy.zip`。
两种包都不含真实API密钥、验证码设置密钥、绑定库、业务数据或已解锁会话。
私有包含维护实现，只由所有者保管，不能当成日常分发包。

## 所有者首次部署

1. 在目标电脑、今后实际使用软件的Windows用户下，把私有完整包完整解压到D盘新文件夹。
   不覆盖旧程序目录。双击最外层的 `开始部署（仅所有者）.cmd`，无需另外安装Python。
2. **检查目标电脑**：助手默认识别随包CampusOps目录，也可选择已经解压的程序目录。
   点击检查环境；通过后确认已关闭目标软件、Windows用户正确。
3. **完成私有配置**：需要AI时，填写API密钥、HTTPS服务地址和模型名称并保存。
   默认预填豆包接口及关闭思考模式；其他兼容模型由所有者填写实际参数。
   已有有效配置可检查后沿用；更换时须明确勾选先加密备份再替换。
   新密钥不进入命令行或报告；已有密钥不回显，留空可在更新时沿用。
   普通模式可跳过AI配置，日常启动仍默认不启用AI。
4. 同一页点击“检查现有绑定”。已有有效绑定直接沿用。
   新电脑点击“导入原手机记录”，由你在本机私有窗口填写原记录的32位设置密钥及当前六位码。
   不新建手机记录、不直接复制另一台电脑的安全库。源电脑的密钥仍通过既有私有工具验证原码后查看。
   旧格式点击“保留记录升级”，仍需明确确认、原验证码及加密备份；损坏状态不会自动重建。
5. **检查并开始使用**：点击检查所选模式能否启动。检查只启动并停止自己的本地服务，
   不打开预约库、不进入已解锁页面、不发送模型请求。通过后点击打开日常软件，
   按需勾选AI与账户保护确认，并用手机下一轮验证码正常解锁。
6. 部署完成后自行收回私有维护工具。普通使用者日常只需打开程序、选择模式、输入验证码。

## 重复部署与保留现有成果

助手不自动读取其他项目、搜索私人密钥、导出当前绑定、同步其他电脑配置或覆盖已安装目录。
仅明确保存所选目录的AI配置；替换时先用当前Windows用户DPAPI保护旧文件备份，
保存在该目录 `var/owner-config-backups`，不能将此目录用于公开分发。
并发保存、检查后文件变化、备份失败、写入失败均停止保存，原文件保留。
不修改预约、审批、审计、验证码失败次数、已用时间步或API预算账本。
新目录不会自动继承旧目录的AI配置或业务数据；本助手不承担业务库迁移或预算迁移。

当前支持Windows x64、有D盘、Edge及.NET Framework 4。组件被系统应用控制阻止时，
按环境诊断处理；工具不会安装证书、添加排除项、提权或关闭安全软件。
既有安全目录权限检查和调整继续使用单独工具，经记录与确认后操作，助手不自动调整。

检查通过只代表本地启动检查通过，不代表真实模型请求、完整业务流程或另一台物理电脑已验收。
工具不能免除首次由所有者受控配置，也不构成许可证、账号体系、服务器授权或绝对防破解方案。
