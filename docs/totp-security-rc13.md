`dbc29212e7e43f5964b963ad6a698a9ceefd1a77db2c85f3ecdbb40dd14d2631`。
本轮不回退、不覆盖旧包，不重写 Agent、预约、确定性约束、事务审批或模型预算。
附加的预约有效/取消分区和滚动修复由原 App UI 文件所有者交付后集成。

运行时只接受严格格式2。解密成功后仍检查字段集合、重复JSON键、类型（bool不冒充int）、
版本、应用、配置、有效种子格式、有限时间及范围、计数和冷却关系。计数和修订都置于DPAPI内部。
修订号只用于状态一致性，**不是可信防回滚锚点**。外层镜像既不能降低限制，也不能作为会话/冷却显示的独立权威。
TOTP使用真实系统时间；会话仍使用单调时钟；演示日期和API预算日不参与认证。

所有者工具与日常内容物理分开，私有源码留在 `maintenance/`，不会安装到 wheel、site-packages、
资源ZIP、入口脚本或缓存。正常程序不包含初始化二维码、新种子生成、重绑定、旧格式迁移或恢复实现。
独立所有者工具本身不是不可伪造的密码学身份：持有源码/同Windows用户解密能力的人仍可以改程序。
没有新增账号、密码、硬件标识、TPM、服务器、遥测、反调试或免验证演示开关。

正常换绑：旧码通过同一 `verify_and_consume` 限速/重放路径，生成只存在本工具进程内的120秒单次授权，
绑定原config_id、代次和rebind操作；新码确认成功且事务内配置仍相符才替换。新确认失败不换绑；授权已消费，
再次尝试必须重新验证旧码。静态文字只防误操作。成功更新config_id，原会话下次受保护调用立即失效。

私有恢复流程：手机遗失时先关闭全部实例，保留状态和加密备份；使用所有者单独保管的验证器备份恢复原记录。
若原记录完全无法恢复，由所有者另行确认离线维护方案、记录备份来源及影响，不提供正常锁定页自助恢复，
不自动恢复旧状态，不把维护工具的持有当作强身份。本轮不执行真实恢复，也不交付绕过旧码的常用重绑命令。
DPAPI备份依赖相应用户/电脑，无法解密不转明文、不降级、不清零；备份不要公开。

剩余边界必须分开理解：

- **完整有效旧快照回滚仍未解决**。隔离测试恢复完整旧SQLite快照后，原消费记录也随之回退；无外部可信单调锚点不能识别全部有效旧快照。
- 同一Windows用户下有解密及写文件权限的恶意进程可以解密后重保护；本次只阻止裸字段低成本改写，不能阻止该能力。
- 能任意修改Python/入口代码、本机管理员、调试或秘密提取者可以绕过应用逻辑；不宣称绝对防破解或禁止复制部署。
- 旧格式迁移不会替旧计数历史补造完整性证明。加密当前值不等于证明其过去可信。

真实绑定迁移和真实ACL调整待所有者本机确认；异机DPAPI/桌面结果没有实际目标电脑时为NotRun。
离线替身、真实DPAPI、SQLite进程测试、Windows桌面/浏览器和真实所有者维护分别记入本轮收据。
不调用Google或模型服务，本轮模型请求为0；不触碰业务库、API Key或正式安全库内容。
