## 使用方式

1. 将完整文件夹放在D盘，例如D:\CampusOpsDemo，保留runtime、scripts、assets和docs目录。
2. 双击CampusOps.exe，再点“启动应用”。默认离线，启动本身不发送模型请求。
3. 首次启动由Main初始化10件虚构器材、20条预约。已有可识别数据保留，陌生数据库受控拒绝。
4. 应用以独立Edge窗口显示资源、调度审批、Agent轨迹三页。关闭最后一个本会话窗口或用托盘退出。
   已在本机实际确认只关闭本次会话、后台随最后窗口退出；原8501预览保留。
5. RC4表格为只读完整记录，可在表格内部纵向及横向滚动；故障与审批仍通过页面表单操作。
6. 种子预约日期固定在2026-11-10至11-11。RC5复现单预约样例时，展开表单中的
   “演示时段（虚构数据，需主动选择）”，点击“填入演示时间 · 11月11日 08:00”，
   再填写原因、确认并登记。这等于2026-11-11T00:00:00Z；快捷时间本身不登记、不调用模型。
7. 登记后点击“继续处理本次故障”，再明确点击“生成调整方案”。待审批时核对器材对照，
   点击“批准并更新 N 条预约”才提交事务；生成前须已手动配置并启用模型，否则明确显示不可用。
   当前时间若已晚于固定样例预约，返回“无影响”是合理结果，可主动选择上述演示时段体验。

需要Windows x64、已安装Microsoft Edge与.NET Framework 4；目前只针对本机环境做验证。
无需另装Python、不调整全局PATH或注册表。未签名EXE若被系统策略阻止，保留诊断，交维护者在
允许的验证环境处理签名/验收；当前工程包不承诺绕过本机策略。

## 真实模型配置

公开包不包含密钥、预约数据库或历史调用账本。将.env.example复制为本包根目录.env，手动配置
单一OpenAI兼容服务的MODEL_API_KEY、MODEL_BASE_URL和MODEL_ID；不把密钥发到聊天或提交Git。
本轮Doubao实测显式使用MODEL_THINKING=disabled；其他服务只按其文档手动设置，不自动轮换。
服务商免费额度与账单硬停止必须由使用者确认。启动器中只有同时勾选启用真实AI和账户保护确认，
才启用客户端；实际请求仍由用户处理事故触发。每运行最多6次、每UTC日30次，失败/超时预留不退款。
预算按当前应用根目录计数，不代表服务商账户余额。业务演示重置不会清空预算。
